# Fix My Code Challenge

## Description
This project is part of the Holberton School curriculum.

The goal is to fix existing code without rewriting everything from scratch.
Each task contains buggy code that needs to be analyzed and corrected.

## Tasks

### 0. FizzBuzz
Fix a Python implementation of FizzBuzz.

The program should:
- Print numbers from 1 to N
- Replace multiples of 3 with "Fizz"
- Replace multiples of 5 with "Buzz"
- Replace multiples of both with "FizzBuzz"

## Requirements
- All files must end with a new line
- Code is tested on Ubuntu 20.04 LTS
- Allowed editors: vi, vim, emacs
